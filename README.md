# Docent — Official Landing Page & Marketing Cockpit

Official high-performance landing page for **Docent** (`docentbase.com`), the calm operating system for coaching centers, educators, and institutions.

## Subdomains & Workspaces
- **Main Landing Page:** [https://docentbase.com](https://docentbase.com)
- **Admin / Teacher Cockpit:** [https://admin.docentbase.com](https://admin.docentbase.com)
- **Student & Parent Hub:** [https://student.docentbase.com](https://student.docentbase.com)

## Core Capabilities
1. **Financial Zero-Leakage & Grace Period Fee Engine** (Automated Unpaid Lists & Instant Parent SMS Confirmations)
2. **Multi-Modal Attendance Hub** (Phone Tap, Biometric Optical Scanner, QR Check-in, Paper Backup, and Universal Student Identifier - USI Cross-Batch Auto-Resolver)
3. **Daily 10-Point Homework Rating & Monthly Parent Dossiers**
4. **24/7 Physical Layer Support** (Data Entry as a Service & On-Site Center Visits)

## Tech Stack
- **Framework:** Next.js 14 App Router
- **Styling:** Tailwind CSS & Calm Operator Design System
- **Icons & Motion:** Lucide React & Framer Motion
- **Edge Deployment:** Cloudflare Workers via `@opennextjs/cloudflare`
- **Domain:** `docentbase.com` / `www.docentbase.com`

## Ship & Deployment
```bash
npm run deploy
```
